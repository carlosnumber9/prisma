# One reviewed multilingual editorial batch

Status: accepted.

Prisma publishes Castilian (`es`), Catalan/Valencian (`ca`), Galician (`gl`), Basque (`eu`), Aranese (`oc`) and English (`en`). Castilian provides the editorial reference, always checked against the original programme. The agent prepares all six versions; the maintainer reviews or delegates language review before agreeing on the complete batch.

Approved point titles/texts and topic labels use complete locale maps. Points share stable IDs, order, citations and synthesis revision/review metadata across languages. Any public translation correction increments the shared revision and checks consistency across every version. Original evidence, official names and document titles retain their language. Missing translations block point approval; incomplete drafts remain private.

This trades independent per-language publishing speed for a single auditable agreement and avoids stale translation states. It changes the public contract to schema v3, requiring a coordinated generator/reader rebuild. Independent locale publication would require a new explicit decision about approval, revision linkage and invalidation. Builds and visits never translate or generate prose. Earlier source-preservation and reviewed-content decisions remain in force.
