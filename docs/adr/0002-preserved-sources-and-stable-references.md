# Preserved sources and stable public references

Status: accepted.

Official programme URLs can change while citizen corrections refer to an earlier text. Preserve original snapshots and extractions with hashes, keep formation/area/point identifiers stable, and track editorial revisions independently. Store review material separately from the approved public projection. This increases repository storage and review discipline compared with retaining URLs alone, but allows checking the consulted evidence and tracing corrections without exposing internal notes in the portal.
